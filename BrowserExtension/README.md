# Extensão Chrome: atualização usando a sessão já aberta

Esta extensão não pede senha, não lê cookies e não tem acesso a outras abas.
Quando você clica no ícone dela, ela lê somente o texto que está visível na
aba atual de uso e abre o CreditWatch com os números encontrados.

## Instalar uma vez

1. No Chrome, abra `chrome://extensions`.
2. Ative **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Escolha esta pasta `BrowserExtension`.
5. Fixe o ícone da extensão na barra do Chrome.

## Atualizar

1. Abra o painel **Plan & Usage** do Cursor já logado.
2. Clique no ícone **CreditWatch Live Usage** no Chrome.
3. Se o Chrome perguntar se pode abrir o CreditWatch, autorize.

O mesmo fluxo funciona para a página do Codex quando ela estiver disponível
no navegador. Nenhum dado de conversa, senha ou cookie é enviado ao app.
